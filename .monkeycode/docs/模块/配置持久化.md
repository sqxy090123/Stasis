# 配置持久化模块

**文件**: `settings_store.c` (107 行)

职责：INI 文件读写 (阈值/自动模式/白名单)、注册表开机自启管理、UI 同步回调。

## 存储结构

### `Stasis.ini` (UTF-16 LE, 可执行文件同目录)

```ini
[Settings]
CpuThreshold=85
MemThreshold=90
ThawThreshold=60
AutoMode=1
Whitelist=chrome.exe;code.exe;notepad++.exe
```

| 键 | 类型 | 范围/格式 | 默认值 | 对应字段 |
|----|------|-----------|--------|----------|
| `CpuThreshold` | 整数 | 50-100 | 85 | `g_State.cpuThreshold` |
| `MemThreshold` | 整数 | 50-100 | 90 | `g_State.memThreshold` |
| `ThawThreshold` | 整数 | 30-80 | 60 | `g_State.thawThreshold` |
| `AutoMode` | 整数 | 0/1 | 1 | `g_State.autoMode` |
| `Whitelist` | 字符串 | 分号分隔进程名 | 空 | `g_State.userWhitelist[]` |

### 注册表 (开机自启)

```
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
  "Stasis" = "C:\Path\Stasis.exe"   (REG_SZ)
```

## LoadSettings 详解

```c
void LoadSettings(void) {
    // 整数项
    g_State.cpuThreshold = GetPrivateProfileIntW(L"Settings", L"CpuThreshold", DEFAULT_CPU_THRESHOLD, CONFIG_FILE);
    g_State.memThreshold = GetPrivateProfileIntW(L"Settings", L"MemThreshold", DEFAULT_MEM_THRESHOLD, CONFIG_FILE);
    g_State.thawThreshold = GetPrivateProfileIntW(L"Settings", L"ThawThreshold", DEFAULT_THAW_THRESHOLD, CONFIG_FILE);
    g_State.autoMode = GetPrivateProfileIntW(L"Settings", L"AutoMode", 1, CONFIG_FILE);

    // 白名单字符串
    WCHAR buf[2048] = {0};
    GetPrivateProfileStringW(L"Settings", L"Whitelist", L"", buf, 2048, CONFIG_FILE);
    if (wcslen(buf) > 0) {
        WCHAR* context = NULL;
        WCHAR* token = wcstok_s(buf, L";", &context);
        while (token) {
            while (*token == L' ') token++;  // 去前导空格
            if (*token) {
                EnterCriticalSection(&g_State.cs);
                WCHAR** newList = realloc(g_State.userWhitelist, (g_State.whitelistCount+1)*sizeof(WCHAR*));
                if (!newList) { LeaveCriticalSection(&g_State.cs); break; }
                g_State.userWhitelist = newList;
                size_t len = wcslen(token)+1;
                g_State.userWhitelist[g_State.whitelistCount] = malloc(len*sizeof(WCHAR));
                if (!g_State.userWhitelist[g_State.whitelistCount]) { LeaveCriticalSection(&g_State.cs); break; }
                wcscpy_s(g_State.userWhitelist[g_State.whitelistCount], len, token);
                g_State.whitelistCount++;
                LeaveCriticalSection(&g_State.cs);
            }
            token = wcstok_s(NULL, L";", &context);
        }
    }
}
```

- **缓冲区**: 2048 WCHAR 足够覆盖常见白名单长度
- **分隔符**: `;` (分号)，`wcstok_s` 线程安全分割
- **去空格**: 仅去前导空格，保留进程名内部空格 (如 `My App.exe`)
- **内存管理**: `realloc` 扩容指针数组，`malloc` 逐项复制字符串

## SaveSettings 详解

```c
void SaveSettings(void) {
    WCHAR buf[16];
    swprintf_s(buf, 16, L"%d", g_State.cpuThreshold);
    WritePrivateProfileStringW(L"Settings", L"CpuThreshold", buf, CONFIG_FILE);
    // ... MemThreshold/ThawThreshold/AutoMode 同理 ...

    // 白名单拼接
    WCHAR whitelistStr[2048] = {0};
    EnterCriticalSection(&g_State.cs);
    for (int i=0; i<g_State.whitelistCount; i++) {
        wcscat_s(whitelistStr, 2048, g_State.userWhitelist[i]);
        if (i < g_State.whitelistCount-1) wcscat_s(whitelistStr, 2048, L";");
    }
    LeaveCriticalSection(&g_State.cs);
    WritePrivateProfileStringW(L"Settings", L"Whitelist", whitelistStr, CONFIG_FILE);
}
```

- **原子写入**: `WritePrivateProfileStringW` 内部使用事务性写入，断电安全
- **锁保护**: 白名单拼接时持有 `g_State.cs`，防止监控线程并发遍历导致读取脏数据

## 注册表自启管理

```c
BOOL SetAutoStart(BOOL enable) {
    HKEY hKey;
    if (RegOpenKeyExW(HKEY_CURRENT_USER, REG_KEY, 0, KEY_SET_VALUE, &hKey) != ERROR_SUCCESS) return FALSE;
    if (enable) {
        WCHAR path[MAX_PATH];
        GetModuleFileNameW(NULL, path, MAX_PATH);
        RegSetValueExW(hKey, REG_VAL, 0, REG_SZ, (BYTE*)path, (DWORD)(wcslen(path)+1)*sizeof(WCHAR));
    } else RegDeleteValueW(hKey, REG_VAL);
    RegCloseKey(hKey);
    return TRUE;
}
```

- **作用域**: `HKCU` 仅当前用户，无需管理员权限
- **值名**: `Stasis` (常量 `REG_VAL`)
- **路径**: `GetModuleFileNameW` 获取当前 EXE 绝对路径

## 线程安全

| 操作 | 线程 | 同步 |
|------|------|------|
| `LoadSettings` | 主线程 (启动) | 单线程，无竞争 |
| `SaveSettings` | 主线程 (UI 交互) | 白名单拼接持有 `cs` |
| `LoadSettings` 白名单填充 | 主线程 | 逐项 `EnterCS`/`LeaveCS` |
| 监控线程读白名单 | 监控线程 | `IsProcessInUserWhitelist` 内部 `EnterCS` 遍历 |
| UI 修改白名单 (待实现) | 主线程 | 需同样持有 `cs` 增删改 |
