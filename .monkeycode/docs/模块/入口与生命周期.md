# 入口与生命周期模块

**文件**: `main.c` (84 行)

唯一职责：进程级初始化/清理、单实例互斥、DPI 感知、消息泵、监控线程启停。

## 核心流程

```mermaid
flowchart TD
    A[wWinMain 入口] --> B[DPI 感知初始化]
    B --> C[--debug 参数解析]
    C --> D[单实例互斥体检查]
    D --> E[通用控件初始化 ICC_LISTVIEW_CLASSES]
    E --> F[全局状态零初始化 + 临界区创建]
    F --> G[默认阈值/标志赋值]

    H --> I[InitProcessAPI 加载 NtSuspend/ResumeProcess]
    I --> J{API 加载成功?}

    J -- 是 --> L[InitLog 打开 Stasis.log]
    L --> M[LoadSettings 读 INI/注册表]
    M --> N[CreateMainWindow 创建主窗口]
    N --> O[g_State.hMainWnd 保存句柄]
```

## 关键实现细节

### DPI 感知 (Per-Monitor V2)

```c
HMODULE hUser32 = GetModuleHandleW(L"user32.dll");
typedef BOOL(WINAPI *SetProcessDpiAwarenessContext_t)(DPI_AWARENESS_CONTEXT);
auto pSet = (SetProcessDpiAwarenessContext_t)GetProcAddress(hUser32, "SetProcessDpiAwarenessContext");
if (pSet) pSet(DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2);
else SetProcessDPIAware();  // 兼容 Win10 1703 前
```

- 必须在 **创建任何窗口前** 调用
- `manifest.xml` 也声明了 `<dpiAwareness>PerMonitorV2</dpiAwareness>` 双重保险

### 单实例互斥体

```c
HANDLE hMutex = CreateMutexW(NULL, FALSE, L"Stasis_SingleInstance_Mutex");
if (GetLastError() == ERROR_ALREADY_EXISTS || GetLastError() == ERROR_ACCESS_DENIED) {
    HWND hPrev = FindWindowW(L"StasisMainWindowClass", L"Stasis");
    if (hPrev) { SetForegroundWindow(hPrev); ShowWindow(hPrev, SW_RESTORE); }
    return 0;
}
```

- 互斥体名固定，跨会话可见 (Global\ 前缀可选，当前为会话内)
- 已有实例 → 激活其窗口 → 静默退出新进程

### 监控线程生命周期

```c
g_State.monitorRunning = TRUE;
g_State.hMonitorThread = CreateThread(NULL, 0, MonitorThread, NULL, 0, NULL);
// ...
// 退出时
g_State.monitorRunning = FALSE;
if (g_State.hMonitorThread) {
    WaitForSingleObject(g_State.hMonitorThread, 2000);  // 最多等 2s
    CloseHandle(g_State.hMonitorThread);
}
ForceThawAll();  // 兜底：无论线程是否正常退出，确保全解冻
```

- `monitorRunning` 为 `volatile BOOL`，线程间可见
- `WaitForSingleObject` 2s 超时防死等，超时仍继续清理

## 测试清单

- [ ] 无参数启动 → 正常显示主窗口
- [ ] `--debug` 启动 → `Stasis.log` 出现 `DEBUG:` 前缀行
- [ ] 双击运行两次 → 第二次激活第一个窗口、无新进程
- [ ] 关闭主窗口 (X/最小化) → 托盘驻留、进程不退出
- [ ] 托盘右键 "全部解冻并退出" → 进程彻底退出、无残留挂起进程
- [ ] 管理员权限缺失 → `InitProcessAPI` 失败 → 弹错退出码 1
- [ ] 极端高负载下强杀进程 → 重启后无僵尸冻结进程
