# 自定义控件模块

**文件**: `ui_controls.c` (198 行)

职责：纯 GDI 实现 **圆角按钮**、**渐变进度条**、**开关**、**滑块** 四类自绘控件，以及滑块鼠标交互子类化。

## 控件概览

| 控件 | 绘制函数 | 用途 | 交互 |
|------|----------|------|------|
| 圆角按钮 | `DrawRoundedButton` | 白名单/托盘/选项按钮 | `WM_DRAWITEM` 仅绘制，点击由父窗口 `WM_COMMAND` 处理 |
| 渐变进度条 | `DrawGradientProgressBar` | CPU/内存状态栏 | 纯显示，无交互 |
| 开关 | `DrawToggleSwitch` | "自动" 开关 | `WM_DRAWITEM` 绘制，父窗口 `WM_COMMAND` 切换状态 |
| 滑块 | `DrawSlider` + `SliderSubclassProc` | CPU/内存/解冻阈值调节 | 子类化处理 `WM_LBUTTONDOWN/MOVE/UP` 实时拖动 |

## 绘制函数详解

### 1. `DrawRoundedButton`

```c
void DrawRoundedButton(HDC hdc, RECT rc, const WCHAR* text, BOOL hover, BOOL pressed) {
    COLORREF bg = pressed ? RGB(80,80,80) : hover ? RGB(100,100,100) : RGB(70,70,70);
    HBRUSH hBr = CreateSolidBrush(bg);
    HPEN hPen = CreatePen(PS_SOLID, 1, RGB(150,150,150));
    HBRUSH oldBr = SelectObject(hdc, hBr);
    HPEN oldPen = SelectObject(hdc, hPen);
    RoundRect(hdc, rc.left, rc.top, rc.right, rc.bottom, 8, 8);  // 圆角半径 8
    SelectObject(hdc, oldBr); SelectObject(hdc, oldPen);
    DeleteObject(hBr); DeleteObject(hPen);

    // 文字
    SetBkMode(hdc, TRANSPARENT);
    SetTextColor(hdc, RGB(220,220,220));
    HFONT oldFont = SelectObject(hdc, g_hBtnFont);
    DrawTextW(hdc, text, -1, &rc, DT_CENTER|DT_VCENTER|DT_SINGLELINE);
    SelectObject(hdc, oldFont);
}
```

- **三态配色**：按下 > 悬停 > 正常
- **字体**：外部传入 `g_hBtnFont` (创建于 `app_window.c:RebuildFonts`)
- **资源管理**：每次绘制创建/销毁画刷/画笔 (频率低，简化管理)

### 2. `DrawGradientProgressBar`

```c
void DrawGradientProgressBar(HDC hdc, RECT rc, double value, COLORREF color1, COLORREF color2) {
    value = clamp(value, 0.0, 100.0);
    int fill = (int)((rc.right-rc.left) * value / 100.0);

    // 背景槽
    HBRUSH hBack = CreateSolidBrush(RGB(60,60,60));
    FillRect(hdc, &rc, hBack);
    DeleteObject(hBack);

    // 渐变填充 (msimg32.dll!GradientFill)
    if (fill > 0) {
        static GradientFill_t pGradientFill = NULL;
        if (!pGradientFill) {
            HMODULE h = LoadLibraryW(L"msimg32.dll");
            if (h) pGradientFill = (GradientFill_t)GetProcAddress(h, "GradientFill");
        }
        if (pGradientFill) {
            TRIVERTEX vert[2] = {
                {rc.left, rc.top,     GetRValue(color1)<<8, GetGValue(color1)<<8, GetBValue(color1)<<8, 0},
                {rc.left+fill, rc.bottom, GetRValue(color2)<<8, GetGValue(color2)<<8, GetBValue(color2)<<8, 0}
            };
            GRADIENT_RECT gRect = {0, 1};
            pGradientFill(hdc, vert, 2, &gRect, 1, GRADIENT_FILL_RECT_H);
        }
    }

    // 边框
    HPEN hPen = CreatePen(PS_SOLID, 1, RGB(100,100,100));
    HBRUSH nullBr = (HBRUSH)GetStockObject(NULL_BRUSH);
    HPEN oldPen = SelectObject(hdc, hPen);
    HBRUSH oldBr = SelectObject(hdc, nullBr);
    Rectangle(hdc, rc.left, rc.top, rc.right, rc.bottom);
    SelectObject(hdc, oldPen); SelectObject(hdc, oldBr);
    DeleteObject(hPen);
}
```

- **动态加载** `msimg32.dll!GradientFill` (系统自带，无额外依赖)
- **双色渐变**：`color1` (左) → `color2` (右)
- **CPU**: 蓝→青 (`0,120,215` → `0,200,255`)
- **内存**: 绿→青绿 (`0,180,120` → `0,255,200`)

### 3. `DrawToggleSwitch`

```c
void DrawToggleSwitch(HDC hdc, RECT rc, BOOL state) {
    // 轨道
    HBRUSH hTrack = CreateSolidBrush(state ? RGB(0,120,215) : RGB(100,100,100));
    SelectObject(hdc, hTrack); SelectObject(hdc, GetStockObject(NULL_PEN));
    RoundRect(hdc, rc.left, rc.top, rc.right, rc.bottom,
              rc.bottom-rc.top, rc.bottom-rc.top);  // 胶囊圆角
    DeleteObject(hTrack);

    // 滑块 (白圆)
    int d = (rc.bottom-rc.top) - 4;
    int xPos = state ? rc.right - d - 2 : rc.left + 2;
    RECT circle = {xPos, rc.top+2, xPos+d, rc.top+2+d};
    HBRUSH hCircle = CreateSolidBrush(RGB(255,255,255));
    SelectObject(hdc, hCircle);
    Ellipse(hdc, circle.left, circle.top, circle.right, circle.bottom);
    DeleteObject(hCircle);
}
```

- **胶囊轨道** + **白色圆形滑块**
- **状态色**：开=蓝 `0,120,215`，关=灰 `100,100,100`
- **动画**：当前无补间，状态切换即时重绘

### 4. `DrawSlider`

```c
void DrawSlider(HDC hdc, RECT rc, int min, int max, int value) {
    // 轨道区 (垂直居中 1/3 高度)
    RECT track = {rc.left, rc.top+(rc.bottom-rc.top)/3, rc.right, rc.bottom-(rc.bottom-rc.top)/3};
    FillRect(hdc, &track, CreateSolidBrush(RGB(80,80,80)));

    // 填充部分
    double ratio = (double)(value-min)/(max-min);
    int fillW = (int)((rc.right-rc.left)*ratio);
    RECT fill = {rc.left, track.top, rc.left+fillW, track.bottom};
    FillRect(hdc, &fill, CreateSolidBrush(RGB(0,120,215)));

    // 滑块拇指 (圆角矩形)
    int thumbX = rc.left + fillW - 5;
    RECT thumb = {thumbX, rc.top, thumbX+10, rc.bottom};
    HPEN hPen = CreatePen(PS_SOLID, 1, RGB(150,150,150));
    HBRUSH hBr = CreateSolidBrush(RGB(200,200,200));
    // RoundRect...
}
```

- **轨道居中**、填充从左到右
- **拇指**：宽 10px，高等于控件高，圆角 4
- **颜色**：轨道灰、填充蓝、拇指浅灰+灰边框

## 滑块交互子类化 (`SliderSubclassProc`)

```c
LRESULT CALLBACK SliderSubclassProc(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp,
                                    UINT_PTR uIdSubclass, DWORD_PTR dwRefData) {
    WNDPROC oldProc = (WNDPROC)GetWindowLongPtr(hwnd, GWLP_USERDATA);
    switch (msg) {
    case WM_LBUTTONDOWN: {
        SetCapture(hwnd);
        POINT pt = {LOWORD(lp), HIWORD(lp)};
        RECT rc; GetClientRect(hwnd, &rc);
        int id = GetDlgCtrlID(hwnd);
        int *pVal=NULL, min=0, max=100;
        if (id==IDC_SLIDER_CPU) { min=50; max=100; pVal=&g_State.cpuThreshold; }
        else if (id==IDC_SLIDER_MEM) { min=50; max=100; pVal=&g_State.memThreshold; }
        else if (id==IDC_SLIDER_THAW) { min=30; max=80; pVal=&g_State.thawThreshold; }
        if (pVal) {
            int w = rc.right-rc.left;
            if (w>0) {
                double ratio = (double)pt.x/w;
                *pVal = min + (int)(ratio*(max-min+1));
                *pVal = max(min, min(max, *pVal));
                *pVal = ((*pVal-min)/5)*5 + min;  // 5% 步进对齐
                InvalidateRect(hwnd, NULL, TRUE);
                SaveSettings();
            }
        }
        return 0;
    }
    case WM_MOUSEMOVE:
        if (GetCapture()==hwnd) {
            // 同 WM_LBUTTONDOWN 计算逻辑，实时更新
        }
        break;
    case WM_LBUTTONUP:
        ReleaseCapture();
        SaveSettings();
        break;
    }
    return CallWindowProc(oldProc, hwnd, msg, wp, lp);
}
```

**关键点**：

| 点 | 说明 |
|----|------|
| `SetWindowSubclass` | `app_window.c:178-180` 三个滑块各自子类化，`uIdSubclass` = 控件 ID |
| `GWLP_USERDATA` | 存原 `WNDPROC`，`CallWindowProc` 转发未处理消息 |
| `SetCapture`/`ReleaseCapture` | 拖动期间鼠标离开控件仍跟踪 |
| `5% 步进` | `((val-min)/5)*5+min` 强制对齐刻度 |
| `InvalidateRect` | 触发 `WM_DRAWITEM` 重绘滑块 |
| `SaveSettings()` | 拖动中实时保存 (`WM_MOUSEMOVE`/`WM_LBUTTONUP`) |
