## 托盘数据结构

```c
static NOTIFYICONDATAW nid = {0};  // 静态全局，进程生命周期内唯一
```

初始化 (`CreateTrayIcon`)：

```c
nid.cbSize = sizeof(NOTIFYICONDATAW);
nid.hWnd = hwnd;                    // 接收 WM_TRAYICON 的窗口
nid.uID = 1;                        // 图标 ID
nid.uFlags = NIF_ICON | NIF_MESSAGE | NIF_TIP;
nid.uCallbackMessage = WM_TRAYICON; // 自定义消息 (WM_APP+1)
nid.hIcon = LoadIconW(GetModuleHandleW(NULL), L"APP_ICON");  // 资源图标
if (!nid.hIcon) nid.hIcon = LoadIconW(NULL, IDI_APPLICATION); // 兜底
wcscpy_s(nid.szTip, _countof(nid.szTip), L"Stasis");
Shell_NotifyIconW(NIM_ADD, &nid);
```

## 右键菜单结构

| 菜单项 ID | 文字 | 行为 |
|-----------|------|------|
| `ID_TRAY_SHOW` (2001) | "显示主界面" | `ShowWindow(hwnd, SW_RESTORE)` + `SetForegroundWindow` + `trayVisible=FALSE` + 恢复进程优先级 `NORMAL_PRIORITY_CLASS` |
| `ID_TRAY_PAUSE` (2002) | "暂停自动模式" | `g_State.pauseAuto = !g_State.pauseAuto` (菜单项 `MF_CHECKED` 反映状态) |
| `ID_TRAY_EXIT` (2003) | "全部解冻并退出" | `DestroyWindow(hwnd)` → 触发 `WM_CLOSE` → 隐藏 → `WM_DESTROY` 清理退出 |

```c
HMENU hMenu = CreatePopupMenu();
AppendMenuW(hMenu, MF_STRING, ID_TRAY_SHOW, L"显示主界面");
AppendMenuW(hMenu, MF_STRING | (g_State.pauseAuto ? MF_CHECKED : 0), ID_TRAY_PAUSE, L"暂停自动模式");
AppendMenuW(hMenu, MF_STRING, ID_TRAY_EXIT, L"全部解冻并退出");
POINT pt; GetCursorPos(&pt);
SetForegroundWindow(hwnd);  // 关键：否则菜单可能不响应键盘/失焦即关
int cmd = TrackPopupMenu(hMenu, TPM_RETURNCMD | TPM_RIGHTBUTTON, pt.x, pt.y, 0, hwnd, NULL);
switch (cmd) { ... }
DestroyMenu(hMenu);
```

## 消息处理 (`app_window.c:388-395`)

```c
case WM_TRAYICON:
    if (lParam == WM_RBUTTONUP) ShowTrayMenu(hwnd);
    else if (lParam == WM_LBUTTONDBLCLK) {
        ShowWindow(hwnd, SW_RESTORE);
        SetForegroundWindow(hwnd);
        g_State.trayVisible = FALSE;
        SetPriorityClass(GetCurrentProcess(), NORMAL_PRIORITY_CLASS);
    }
    break;
```

| 事件 | `lParam` | 动作 |
|------|----------|------|
| 右键单击 | `WM_RBUTTONUP` | 弹出菜单 |
| 左键双击 | `WM_LBUTTONDBLCLK` | 恢复窗口、取消托盘驻留、恢复正常优先级 |

## 优先级切换

| 场景 | 优先级 | 目的 |
|------|--------|------|
| 正常运行 | `NORMAL_PRIORITY_CLASS` | 响应及时 |
| 隐藏到托盘 | `BELOW_NORMAL_PRIORITY_CLASS` | 让出 CPU 给前台应用，降低自身干扰 |
| 托盘双击恢复 | `NORMAL_PRIORITY_CLASS` | 恢复交互优先级 |

## 扩展建议

| 功能 | 实现思路 |
|------|----------|
| **托盘图标动态变色** | `UpdateTrayIcon(frozenCount)` 中根据 `frozenCount>0` 切换 `LoadIconW` 不同图标 (红/绿/灰)，`Shell_NotifyIcon(NIM_MODIFY)` 更新 |

| **菜单项本地化** | 字符串移至资源表 `STRINGTABLE`，`LoadStringW` 加载 |
| **托盘左键单击恢复** | 当前仅双击，可在 `WM_TRAYICON` `WM_LBUTTONUP` 也触发恢复 |
| **高 DPI 托盘图标** | 提供 16/20/24/32px 多尺寸 `.ico`，Windows 自动选择 |
| **启动时最小化到托盘** | `main.c` 解析 `--minimized` 参数 → `CreateMainWindow` 后直接 `ShowWindow(SW_HIDE)` + `CreateTrayIcon` |
