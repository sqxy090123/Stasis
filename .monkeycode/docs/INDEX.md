# Stasis 文档索引

**Stasis** 是一个 Windows 原生进程管理工具，在系统资源（CPU/内存）紧张时自动冻结高占用后台进程，释放资源给前台应用，防止系统卡顿。

## 核心概念

理解这些领域概念有助于导航代码库：

| 概念 | 描述 | 文档 |
|------|------|------|
| [冻结栈](./专有概念/冻结栈.md) | LIFO 结构管理被挂起进程 PID，支持后进先出解冻、前台唤醒移除 | 核心数据结构 |
| [阈值体系](./专有概念/阈值体系.md) | 冻结阈值 (CPU≥85%/内存≥90%) 与解冻阈值 (≤60%) 形成滞回，避免抖动 | 调度核心参数 |
| [白名单机制](./专有概念/白名单机制.md) | 系统关键进程静态白名单 + 用户动态白名单 (INI 持久化)，线程安全读写 | 保护机制 |
| [看门狗](./专有概念/看门狗.md) | UI 线程心跳计数器，2 秒无响应触发强制全量解冻 + 用户告警 | 容错兜底 |
| [前台唤醒](./专有概念/前台唤醒.md) | 检测前台窗口 PID 在冻结栈中 → 立即解冻并移除，保障交互流畅 | 交互优化 |

## 快速参考

### 命令

```bash
# 构建
build.bat                    # 默认版本 1.0.0.<run_number>
build.bat 1.2.3.4            # 指定版本
build.bat dev-abc123         # 开发版

# 运行 (需管理员)
Stasis.exe
Stasis.exe --debug           # 启用调试日志

# 查看运行产物
type Stasis.log              # 运行日志
type Stasis.ini              # 用户配置
```

### 重要文件

| 文件 | 用途 |
|------|------|
| `Stasis.h` | 全局类型、宏、外部声明 (所有模块入口) |
| `main.c` | 程序入口、单实例、消息循环 |
| `app_window.c` | 主窗口过程、UI 布局、自绘分发 |
| `process_manager.c` | 进程挂起/恢复核心、白名单/关键进程判断 |
| `monitor_engine.c` | 监控线程、冻结/解冻调度、看门狗 |
| `ui_controls.c` | 自绘控件实现 (按钮/进度条/开关/滑块) |
| `tray_icon.c` | 托盘图标、右键菜单 |
| `settings_store.c` | INI/注册表配置持久化 |
| `log.c` | 线程安全日志、自动轮转 |
| `build.bat` | 编译脚本 (版本号、编译器/链接器参数) |
| `resource.rc` | 图标、清单、版本信息资源 |
| `manifest.xml` | 管理员权限 + PerMonitorV2 DPI 感知 |
| `.github/workflows/build.yml` | GitHub Actions CI/CD |
